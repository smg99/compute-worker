# Future Workload Roadmap

The current architecture supports the `test-compute` provider. Future workload categories that the architecture is designed to eventually support include:

- **Deterministic Compute:** Harmless CPU workloads used for verification or simple tasks.
- **AI / Local Inference:** Running small on-device LLMs or ML models for products.
- **Browser-Assisted Compute:** Offloading tasks back to secure browser contexts where necessary.
- **Distributed Jobs:** Coordinated tasks across the fleet (data processing).
- **Mining / Provider Workloads:** Where legally and technically appropriate, specific cryptocurrency mining or verified computational provider tasks (e.g., XMRig).
- **X Founder Workloads:** Specific execution tasks tied to the Founder ecosystem.
- **Future Product Workloads:** Unforeseen product requirements implemented through the `WorkloadProvider` adapter pattern.
